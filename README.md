## CountryScope
CountryScope is an interactive platform designed to explore countries around the world. It provides detailed and real-time information about each country, including geographical data, languages, currencies, weather conditions, and much more.

Whether you're a geography enthusiast, a traveler, or just curious about the world, CountryScope aims to provide you with the most accurate and engaging insights.

Features

Explore Countries: View detailed country information such as name, capital, population, region, and more.

Geographical Data: Learn about country flags, maps, and area size.

Languages & Currency: Discover the official languages and currency used in each country.

Weather Information: Stay updated with real-time weather conditions such as temperature and weather description.

Timezones & Calling Codes: Easily access timezones and calling codes for each country.

Responsive Design: Fully responsive interface to provide a seamless experience on both desktop and mobile devices.
